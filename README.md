# Carcare 🚗

**Carcare** is an Android application designed for vehicle dashboard management and speed monitoring, built using Java and modern Android Architecture Components.

## Features
- **Dashboard Speed Tracking:** Monitor and adjust vehicle speed in real-time.
- **MVVM Architecture:** Uses `ViewModel` to handle state persistence and separation of concerns.
- **Clean UI:** Simple and responsive user interface built with Android XML layouts and Material components.

## Tech Stack
- **Language:** Java
- **Architecture:** MVVM (Model-View-ViewModel)
- **Min SDK / Target SDK:** Android SDK
- **Build System:** Gradle (Kotlin DSL)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/Carcare.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle and run the app on an emulator or physical Android device.
